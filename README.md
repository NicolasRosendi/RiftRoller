# RiftRoller

Draft aleatorio (Roller), armado manual de composiciones (Picker) y simulador de partidas de League of Legends.
Sitio estático sin build: `index.html`, `styles.css` y `js/`.

- `js/data.js`: campeones, líneas y cambios de los últimos parches (`PATCHES`).
- `js/builds.js`: runas, hechizos, páginas recomendadas y editor de runas.
- `js/app.js`: Roller, Picker, análisis y simulación.

## Deploy en Render (Static Site)

- **Branch:** `main`
- **Build Command:** dejar vacío
- **Publish Directory:** `.`

O usar el `render.yaml` incluido (New → Blueprint).
